Activity 3 – Web Technologies

Project Description

This project is a personal website developed using HTML, CSS, and JavaScript. It presents personal information, hobbies, a learning plan, photographs, media, projects, skills, and a contact form.

Technologies Used

* HTML5 – Structures the website content.
* CSS3 – Styles the website and makes it responsive on different screen sizes.
* JavaScript – Adds interactivity and form validation.

Website Features

* Responsive navigation and page layout.
* About Me section with Read More and Read Less functionality.
* Hobbies and learning plan sections.
* Photo gallery.
* Video and audio media.
* Contact form with input validation and a message preview.
* Light and dark theme switch.
* Project and skills search/filter functionality.
* Keyboard focus styling for accessibility.

How to Test

1. Open the deployed website using its public Render URL.
2. Navigate through the website sections.
3. Test the theme switch and Read More/Read Less controls.
4. Search for projects or skills and test the reset function.
5. Submit the contact form with empty fields, an invalid email, and valid information.
6. Play the video and audio.
7. Test the layout on desktop and mobile screen sizes.

Note: The contact form validates the input and previews the message; it does not send messages to an email address.
